Coloca aquí los dos archivos que publica la página, con ESTOS nombres exactos:

  pdfsv.apk        -> la aplicación Android
  documento.pdf    -> la documentación

Si quieres usar otros nombres, cámbialos también en index.html
(atributos href="downloads/...") y en netlify.toml.

Dos formas de actualizarlos:

  1. Terminal:  reemplaza los archivos y haz
     git add . && git commit -m "nueva version" && git push

  2. Panel privado (sin terminal):
     abre  https://<tu-sitio>.netlify.app/panel-9k4m2xqz/
     (ver README.md -> "Opción B - panel privado")

Netlify redespliega solo en 1-2 minutos.

Tamaño del APK: GitHub RECHAZA archivos de más de 100 MB.
Si tu APK supera los 100 MB, usa GitHub Releases (ver README.md).
