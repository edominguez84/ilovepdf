Cómo instalar el APK

  1. Descarga el archivo .apk en tu teléfono Android con el botón de arriba.
  2. Abre el archivo descargado. Android pedirá permiso para instalar apps de orígenes desconocidos: actívalo para este navegador.
  3. Pulsa Instalar y espera a que termine. Ya puedes abrir MiApp desde el cajón de aplicaciones.
